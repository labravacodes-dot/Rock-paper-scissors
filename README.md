# 🥷 Rock Paper Scissors: Shinobi Edition - Road to Ninja 🤌

An immersive, anime-themed Rock Paper Scissors game built with vanilla JavaScript, HTML5, and CSS3, featuring a custom shinobi spin, Genjutsu visuals, and dynamic audio controls.

---

## 📜 Origin Story: From Generic Code to a Shinobi Vision

This project originally began as part of the standard **Rock Paper Scissors** assignment from **The Odin Project**. However, during Step 4, I realized that the predetermined, generic tutorial path didn't feel right. I couldn't commit to building something without a soul or unique identity. 

I decided to completely pivot and inject a full-fledged anime narrative into the core mechanics. What started as basic console logging evolved into a fully realized interactive web app—complete with custom lore, an atmospheric Genjutsu background, frosted glassmorphism UI design, and dynamic audio controls. This README documents that evolution and the process of bringing this vision to life.

---

## 🌟 Project Overview & Features

* **The 5-Point Core Loop**: A modified scoring system where the first player to reach 5 points triggers unique anime-themed end-game dialogues.
* **Lore-Based Victory Conditions**: 
  * **Ultimate Victory (5 Points)**: The Hokage arrives in person to congratulate your strength and invite you to Ichiraku Ramen!
  * **Defeat**: A reminder of the *Road to Ninja*, prompting a journey to Mount Myoboku and the Falls of Truth for Sage Mode training.
* **Custom Dialogue & Chakra Flow**: Dynamic messages for ties ("equilibrium of battle, just like your current chakra flow"), wins, and losses against your persistent opponent: *"Your Next Door Sparring Partner That Always Comes Back Asking For More"*.
* **Genjutsu Aesthetics**: Immersive crimson moon background (`shinobi.jpg`) paired with a modern dark glassmorphism container UI (`backdrop-filter`).
* **Interactive Audio Integration**: Built-in background music track (`bgm.mp3`) with an active mute/unmute toggle button and automated interaction triggers.
* **Hybrid Tracking**: Functional DOM UI updates accompanied by ninja hand-sign logs (`Ninpo: Rokku no Jutsu!`, etc.) in the console.
